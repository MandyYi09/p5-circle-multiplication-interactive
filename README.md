# 数学花园 · 圆上的乘法

一个使用 p5.js 的交互数学作品。用简单的乘法和取模，在圆上生成心脏线轮廓、双叶曲线和编织图案。

## 运行

直接用浏览器打开 `index.html` 即可，不需要安装 npm 包。p5.js 1.11.11 保存在 `vendor` 中，页面无需联网。

也可以在此文件夹中启动静态服务器：

```sh
python3 -m http.server 8000
```

然后访问 http://localhost:8000 。

## 玩法

- 拖动乘数（0–100）和点数（20–600），实时观察连线变化。
- 点击三个种子预设，探索不同图形。
- 点击「让它生长」或按空格，自动改变乘数；再次点击暂停。
- 将指针移动到圆周附近，查看单条连线的计算。
- 切换四种配色，或保存当前画布为 PNG。
- 点击重置恢复初始状态。初始画面静止，动画由用户手动开启。

## 原理

在圆周上等距放置 N 个点，编号为 0 到 N−1。对每个编号 i，连接起点 i 与终点 `(i × m) mod N`。终点可以不是整数，此时它位于对应的圆周角度，而不是把编号四舍五入。

点的位置为：

```
θ = 2π × i / N − π/2
x = cx + r × cos(θ)
y = cy + r × sin(θ)
```

当 m = 2 时，足够密集的连线会形成心脏线的包络轮廓；每一笔依然是直线。有限点数只是离散近似。m = 3 时可观察双叶轮廓；更大的乘数与不同点数会产生复杂的离散结构。

## 文件

- `index.html`：界面和中文说明。
- `style.css`：响应式布局与配色。
- `sketch.js`：p5.js 绘图、参数、动画与导出。使用 instance mode。
- `vendor/p5.min.js`：本地 p5.js 库。
- `vendor/p5.LICENSE.txt`：p5.js 的 LGPL-2.1 许可证。
